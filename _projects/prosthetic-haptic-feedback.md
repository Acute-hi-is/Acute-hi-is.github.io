This project focuses on developing a wearable vibrotactile feedback system for people who use lower-limb prosthetic knees and ankles. Many prosthesis users face challenges in safely and confidently controlling their devices, partly due to limited sensory feedback. This research aims to address that gap by providing intuitive vibration-based information about the prosthesis state and function. Using a user-centered and iterative design approach, the project explores how feedback should be delivered, where tactile actuators should be placed, and which vibration patterns are most effective, comfortable, and usable. Prototypes will be developed, refined, and evaluated through technical testing and user feedback.
